# Supplementary learning curve v013

本实验在已经使用过的 Validation 窗口上，补充检查冻结 Adam 配置下 BL2（BL1 + 18 个 H2 历史特征）的训练规模敏感性和额外过拟合风险。

它不属于 v010–v012 确认链，不重建 Silver/特征，不重新选择优化器、学习率、步数、正则化或 H2 特征。结果不能修改 v010–v012 已冻结结论，也不能表述为新的 pristine confirmation。

实验包含两个设计：

1. `B_user_cluster_subsample`（主实验）：训练窗固定为 2022-04-08 至 04-16，按用户簇做 10%/25%/50%/75%/100% 的嵌套下采样，三个冻结抽样种子；校准和 Validation 窗口保持全量固定。
2. `A_training_window`（辅助实验）：训练末日固定为 04-16，训练起点依次为 04-15/04-13/04-11/04-09/04-08；它衡量带标签训练时间窗，不代表 H2 回看长度发生改变。

主推断量是在完全相同 Validation 行上的 `BL2 - BL1` 成对差值，使用 2,000 次用户簇 bootstrap。训练集指标和 train–Validation 间距只作为描述性诊断。

正式运行前必须通过专项测试、输入/实现哈希预检、CUDA 检查，并取得 `contract_v013.yaml` 精确 SHA-256 的项目所有者批准。正式输出写入本目录的 `outputs/`，不会覆盖既有实验。
