# Gate 2B 全七日 GPU 探索实验结果（v001）

> 结论边界：这是项目所有者授权的完整 Train-only GPU 探索实验。它使用全部七个 rolling-origin 和冻结输入，但 PyTorch Adam 不等同于 canonical v003 的 sklearn SGD，因此不能标记为 canonical release 或独立确认性证据。

## 结论先行

GPU 协议下，BL1/BL2 的绝对概率质量门与 BL2 相对 BL1 的历史增量门均通过。这支持“严格历史在该 GPU 训练协议中同时改善排序与概率质量”的 Train-only 探索性结论；仍需 canonical sklearn release 才能决定正式 Gate 2B 状态。

## 结果分析

- **提升幅度有实际量级**：相对 BL1，BL2 的 AP 提高 `0.041295`（相对提升约 `7.59%`），user-GAUC 提高 `0.048758`（约 `8.08%`）；同时 Log Loss 降低约 `4.14%`、Brier 降低约 `4.76%`。这说明历史特征不只是改变排序，也改善了概率误差。
- **逐日方向稳定**：7 个 assessment 日中，BL2 的 AP 均高于 BL1，user-GAUC 均不低于 BL1；因此 pooled 提升不是由单日异常主导。
- **统计不确定性较小**：BL2−BL1 的 AP、user-GAUC、Log Loss、Brier 四类核心增量的 95% 用户聚类 bootstrap 区间均未跨过 0。最关键的 AP 区间为 `[+0.037661, +0.045054]`。
- **收益覆盖不同历史深度**：BL2 在 `0–49`、`50–199`、`200+` 历史切片中的 AP 增量均为正；短历史组增量最大（`+0.115524`），但该组仅 `16,596` 行，应作为探索信号，而非“历史越短收益一定越大”的定论。占主体的 `200+` 组仍有 `+0.037361`，说明总体收益并非只来自冷启动用户。
- **概率输出健康**：pooled BL2 的 ECE20 为 `0.005146`；预测落到 `≤0.01` 的比例仅 `0.0817%`，`≥0.99` 为 `0`，没有极端概率饱和。BL2 的逐日 sigmoid calibration slope 为 `0.9739–1.0167`，接近理想尺度 1。
- **Demo 建议**：将 BL2 作为本次 GPU demo 的主结果、BL1 作为无历史对照；对外表述限定为“冻结 Train-only、七日 rolling-origin 下的稳定探索结果”，不要表述为测试集泛化或线上因果提升。

## 实验范围与实现

- 数据：冻结 Train-only 特征矩阵，SHA-256 `4981ee32c4c367bf42f27fdff81171e2bedbe5eb7fabf66d6b3e2796b9e428cd`。
- 样本：七日 assessment 共 `1,641,098` 行，`943` 个用户。
- GPU：`NVIDIA GeForce RTX 5070 Ti`，PyTorch `2.11.0+cu128`。
- 特征：BL1 静态稀疏特征；BL2 在 BL1 上增加严格 point-in-time 用户历史。
- 校准：只使用 assessment 前一日数据的 sigmoid calibration。
- 推断：2,000 次 paired user-cluster bootstrap。
