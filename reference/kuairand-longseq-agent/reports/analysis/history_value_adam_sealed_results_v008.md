## 结论边界与下一步

现在可以把结论从“Validation 有效”升级为：在冻结 GPU Adam 的离线候选响应协议下，严格时点历史相对相同静态基线，在两个连续时间外标准曝光窗口中稳定提高预测质量。

当前仍不能声称：

- 效应能够迁移到正式 random exposure；
- 结论对 SGD 或其他优化器稳健；
- 离线预测提升代表因果效应或线上业务收益。

若继续预注册路线，下一步是单独解锁 random audit，使用 sealed 阶段冻结的模型和校准器、不在 random 标签上重拟合，检验曝光分布变化下的迁移性。random 失败不会抹去 Validation 与 sealed 的标准曝光结论，但会把结论范围限制在标准曝光。
