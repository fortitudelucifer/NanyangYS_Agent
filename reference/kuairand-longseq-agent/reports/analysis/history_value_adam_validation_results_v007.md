## 证据强度、限制与下一步

Validation 给出了方向一致、超过 SESOI、CI 完全远离零、逐日 4/4 一致且损失指标同步改善的证据。因此在冻结的 GPU Adam 协议下，可以判定“历史在 Validation 有预测价值”。

当前不能声称：

- 效应已经通过 2022-04-22 至 05-08 的时间外 sealed test；
- 效应能够迁移到 random exposure；
- 结论对 SGD 或其他优化器稳健；
- 离线预测提升代表因果效应或线上业务收益。

基于预注册路线，下一步建议解锁 sealed test，但仍保持 random audit 锁定；先检验该效应能否在更长、更晚的 17 天窗口持续，再根据 sealed 结果决定是否进入 random audit。
